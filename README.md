# AdventureWorks-Sales-Dashboard-using-power-bi
AdventureWorks Sales Dashboard using power bi

A Power BI report built on the AdventureWorks Sales dataset, modeled around a star schema with a dedicated DAX measures table and drill-down analysis.

What was done
Imported and transformed Sales.xlsx, including additional data transformations
Built a star schema data model with a product hierarchy (Category → Subcategory → Product)
Created a centralized DAX measures table containing: # Orders, # Order Details, Total SubTotal, Total Tax, Total Freight, and Total Due
Designed KPI cards for each measure, plus:
Orders by Order Date
Orders by Status
Order Quantity by Category, Subcategory, and Product (with drill-down)
Orders vs. Total Due by Territory
Added a tooltip page for contextual detail on hover
Focused on a clean, consistent visual design — meaningful chart titles, cohesive color palette, and clear layout
Tools

Power BI · DAX · Power Query · Star Schema Modeling

Deliverables
Power BI report (.pbix)
